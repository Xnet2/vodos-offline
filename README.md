# VODOS אופליין — לנגן, בלי אינטרנט

הפיד של [VODOS](https://xnet2.github.io/VOD/) על נגן MP4/MP5 עם אנדרואיד (או כל מכשיר אנדרואיד), בלי חיבור לאינטרנט.
המחשב מוריד את הסרטונים החדשים מכל המקורות, וכשמחברים את הנגן ב-USB הוא מעתיק אליו אותם אוטומטית.

## הורדה

- **האפליקציה לנגן:** [VODOS.apk](https://github.com/Xnet2/vodos-offline/releases/latest/download/VODOS.apk)
- **התוכנה למחשב (Windows):** [VODOS-PC.zip](https://github.com/Xnet2/vodos-offline/releases/latest/download/VODOS-PC.zip)

## התקנה

1. **בנגן:** מעתיקים את `VODOS.apk` לנגן, פותחים אותו במנהל הקבצים ומתקינים (אם מתבקש — לאשר התקנה ממקור לא ידוע).
   **פותחים את האפליקציה פעם אחת** — כך המחשב יזהה את הנגן.
2. **במחשב:** פורסים את `VODOS-PC.zip` ולוחצים פעמיים על `install.cmd`.
   התוכנה תרוץ ברקע ותופעל אוטומטית בכל הדלקה של המחשב (אם חסר Node.js — היא מתקינה אותו).
3. **מחברים את הנגן ב-USB** (מצב העברת קבצים / MTP). כשמופיעה ההודעה "הועתקו X סרטונים חדשים" — אפשר לנתק.

## איך זה עובד

- כל רבע שעה המחשב מוריד את הסרטונים החדשים (מהטבלה של האתר), עד 2GB של האחרונים.
- כשמתחבר מכשיר שמותקנת בו האפליקציה, מועתק אליו מה שחסר, לתיקייה `Android/data/il.vodos.offline/files`
  (בכרטיס הזיכרון, אם יש). תמיד נשארים לפחות 500MB פנויים.
- האפליקציה מציגה את הפיד כמו באתר — "עדכני" / "לא נצפו", בחירת מקור, טשטוש ולוגו בסוף סרטון — ומוחקת בעצמה סרטונים ישנים.
- סרטונים שאי אפשר להוריד (פרוג חוסמים הורדה מחוץ לאתר שלהם, או קובץ שנטפרי עוד לא אישר) — מדלגים עליהם ומנסים שוב אחר כך.
- יומן: `%LOCALAPPDATA%\VODOS-M36\log.txt`

## דרישות

- נגן / מכשיר עם אנדרואיד 4.4 ומעלה.
- מחשב Windows 10/11.

## בנייה

`sh app/build.sh` (ב-Git Bash) — בונה את `VODOS.apk` עם JDK 17 ו-Android build-tools 34 / platform 34, בלי Gradle.
התיקייה של הכלים נקבעת ב-`BUILD` שבראש הסקריפט.
